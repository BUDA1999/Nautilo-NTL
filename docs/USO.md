# Uso

1. Obtém uma chave em [OpenRouter](https://openrouter.ai/keys).
2. Inicia `~/ntl/ntl` e guarda a chave na opção `a`.
3. Usa chat rápido para uma pergunta isolada ou chat em sessão para manter histórico.
4. A quota local limita as chamadas diárias a 45 por defeito; é um contador local, não uma garantia do limite do fornecedor.
5. As conversas são guardadas localmente em `sessions/`. Exportações Markdown aparecem em `exports/`.

A versão `:free` pode registar pedidos para melhoria/treino segundo os termos do fornecedor. Não envies dados confidenciais, chaves, credenciais, dados de clientes ou informação bancária.
